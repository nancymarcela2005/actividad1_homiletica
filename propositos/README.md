# Parejas con propósito

Abre index.html en el navegador. Mantén styles.css y app.js en la misma carpeta. No requiere instalación ni Internet.

Para publicar este proyecto por separado, sube el contenido de esta carpeta a la raíz de un repositorio y activa GitHub Pages desde main, /(root).

Consulta LEEME.md en la carpeta principal del paquete para la dinámica de clase, fuentes, personalización y pasos completos de publicación.
